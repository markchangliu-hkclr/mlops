# v.0.1

## dataset 模块

## 功能

- 数据类型之间的转化
- 数据类型的变换
- 数据类型的 iou 运算
- 数据类型的可视化
- 数据集标注的导入、变换、导出
- 数据集标注类型之间的转化
- 数据集的可视化
- 数据集的指标评估

## 设计原则

- 有一个 `types.py` 模块用于存放所有的类型定义，该模块只依赖标准库和第三方库，不依赖自开发库
- 以实体为模块名称，模块内存放所有以该实体为输入主体的函数和相关 utils 函数
- 内部路径层级最多为2层，即 `datasets/xx.py` 或 `datasets/xx/yy.py`
- 以函数式编程为主，OOP 编程为辅

## 模块设计

```
datasets
| - types.py            # 类型定义
| - bboxes.py           # bboxes 转化、变换、iou 运算、可视化函数
| - polygons.py         # polygons 转化、变换、可视化函数
| - contours.py         # contours 转化、变换、可视化函数
| - masks.py            # masks 转化、变换、iou 运算、可视化函数
| - rles.py             # rles 转化函数
| - labelme.py          # labelme 导入、导出、转化、可视化函数
| - coco.py             # coco 导入、导出、转化、可视化函数
| - yolo.py             # yolo 导出、导出、转化、可视化函数
| - instances.py        # instances 类定义、转化、可视化、评估函数
| - dataset.py          # 
```
